# QandA 管理端

QandA 管理端，使用 React、TypeScript、Vite、Arco Design、TanStack Query 和 Zustand 构建。

当前进入 UI 与交互重设计阶段，围绕“院级管理”和“题库工作台”展开。现阶段保留运营概览与登录流程，并已实现第一版院级管理及题库工作台，其他原有业务页面及其路由、导航入口已删除。

## 本地运行

```bash
cd apps/admin
pnpm install
pnpm dev
```

默认访问地址为 `http://localhost:5174`，测试账号为：

```text
admin / mock
```

## 可用功能

- Mock 管理员登录、未登录保护、记住账号、失败锁定和会话超时；
- 运营概览展示用户、课程、已发布题库和题目统计，以及反馈待办、资源整理提示和近 14 天练习趋势；
- 侧栏依次展示运营概览、院级管理、题库工作台，未恢复的原业务页面地址统一返回运营概览；
- 院级管理采用左侧组织目录、右侧列表，逐层维护学院、专业与入学年级；
- 学院和专业的创建、编辑、搜索、状态筛选、停用及安全删除；
- 一个专业下可一次新增多个年级，支持年级编辑、停用、学生归属查看及安全删除；
- 组织目录搜索保留完整上级路径，上级停用时下级显示“随上级停用”；
- 有下级、学生或题库引用时阻止直接删除；年级已有学生或题库引用时不能直接修改年份；
- 题库工作台按课程组织多份题库，支持课程维护、题库创建、搜索筛选、编辑与安全删除；
- 题库详情提供题目管理、基本信息、展示范围三个页签，支持章节维护及排序、单选/多选/判断/填空/简答录入与编辑，以及阅读材料与小题题组维护；
- 填空支持逐空多个可接受答案与匹配设置，简答支持参考答案及评分要点，阅读题组支持小题排序和展开预览，题数统一按实际小题统计；
- 批量选择 JSON 文件，识别与预览题目，调整文件顺序，整批校验后追加导入；
- 展示范围支持全校可见，以及多组学院、专业、年级条件，年级可多选，并提供学生资料匹配预览；
- 新题库默认草稿，可暂缺范围；发布检查通过后发布，支持下架与归档，已发布题库至少保留一道启用题目；
- 正常、空数据、请求失败、写入失败、慢请求和 1000 道题 Playground 场景；
- 浏览器本地保存 Mock 数据。

运营概览已移除指向其他业务页面的按钮和链接，原有统计与内容展示保留。现有 Gateway、类型、Mock 数据和数据规则继续保留，移除页面不会清空浏览器中的演示记录。切换 Playground 场景仍会重置演示数据。

## 验证

```bash
pnpm test
pnpm build
```

## 运行边界

所有展示使用浏览器本地 Mock 数据，本地登录不具备生产安全能力。现有演示数据升级时补齐年级目录，保留原学生、学习记录及题库状态；新增、编辑、删除会保存到本浏览器，切换 Playground 场景会重置演示数据。

答题端的三级选择及资料变更后的真实题库列表切换尚未接入。本轮在管理端实现范围配置与匹配预览，没有新增访问权限限制。

题目内容更新会递增版本，已有反馈中的原题快照与本地统计记录保留；真实学生练习过程中的题目版本固定仍需要后端实现。

本次调整只覆盖管理端前端，不涉及真实后端、数据库或学生端。
