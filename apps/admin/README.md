# QandA 管理端

QandA 管理端 Independent MVP，使用 React、TypeScript、Vite、Arco Design、TanStack Query 和 Zustand 构建。

## 本地运行

```bash
cd apps/admin
pnpm install
pnpm dev
```

默认访问地址为 `http://localhost:5174`，测试账号为：

```text
admin / mock
```

## 可用功能

- 对照 Figma 管理端 16 个画板重写的分组导航、登录页和页面样式；
- Mock 管理员登录、未登录保护、记住账号、失败锁定和会话超时；
- 运营概览优先展示题目反馈、缺课需求、题库草稿和资源整理提示；保留答题趋势与使用统计；
- 当前大学下的学院增删改查、搜索和状态管理；
- 学院下的专业增删改查、筛选和状态管理；
- 独立共享课程目录，无须先建立学院或专业即可创建课程；
- 题库草稿、教材说明、内容负责人、编辑、筛选、发布、下架和归档；
- 题库工作台集中管理章节、题目、导入、发布检查及学生视角预览；
- 单层章节新建、编辑、排序、空章节删除，以及题目分章和未分章筛选；
- 单选题、多选题、判断题的创建、查看、编辑、删除、搜索和筛选；
- 多个 JSON 文件批量识别、预览、调整顺序、移除及整批校验后导入，可统一归入某个章节；
- 全校适用或按学院、专业、入学年份配置题库推荐条件，并预览不同用户的推荐结果；
- 注册用户筛选、自填资料与自选课程查看、异常账号停用与恢复；
- 题目纠错和缺课需求分类处理、原题快照核对、回复与状态流转；
- 公告搜索、草稿、预览、立即/定时发布设置、指定用户和展示端、撤回与删除；
- 管理员账号增改删及新密码规则校验；
- 登录保护和密码规则设置、关键操作日志筛选与详情；
- 正常、空数据、请求失败、写入失败、慢请求和 1000 道题 Playground 场景；
- 浏览器本地保存 Mock 数据。

学院与专业用于自填资料及推荐分类；课程和题库独立共享。推荐范围不限制学生搜索和访问其他专业内容，“我的课程”由学生自行维护，后台只查看。已有内容、用户资料、自选课程或反馈引用时，删除受到保护。

新题库先保存为草稿，至少有一道启用题目、题库说明和完整解析后才允许发布；编辑及导入不能绕过已发布题库的解析检查。旧版本地演示数据升级时保留原记录，并将原题库转为待检查草稿；不会从旧管理员分配记录擅自生成学生自选课程。

页面只依赖 `AdminContentGateway`。后续联调时可注入 HTTP Gateway，无需重写页面和表单。

## 验证

```bash
pnpm test
pnpm build
```

## 运行边界

所有功能使用浏览器本地 Mock 数据。公告的定时状态在再次读取或列表定时刷新时计算，尚无真实发布任务或跨端推送；新设备验证和首次登录改密暂不可启用，需要接入真实身份服务。本地登录与日志不具备生产安全和审计能力。

本次调整只覆盖管理端与本地 Mock；真实学生注册、学生端加入课程、跨端反馈、服务端练习快照与权限控制仍需接入后端。
