# 首页公告入口

首页右侧以透明 PNG 呈现漫画贴纸风格的筒状喇叭，素材位于 `../miniprogram/assets/home/announcement-megaphone.png`，输出 256 × 256 像素。珊瑚红筒身、明黄口沿与两条声波，以深蓝粗描边和奶油白外轮廓衔接蓝色页头。

素材由内置 imagegen 生成并经用户选定，部署时等比缩小并保留透明通道。生成提示词要点：漫画贴纸图标、右上朝向的筒状喇叭、珊瑚红与明黄纯色块、深蓝粗描边、沿造型的奶油白外轮廓、两条声波、透明背景、小尺寸清晰可辨。

## 布局与交互

- 点击热区 96 × 96rpx，与搜索框保持 16rpx 间隔。
- 喇叭为 108rpx 前景图片，透明背景直接叠在蓝色页头；摇动支点位于窄口尾端 `10% 72%`。
- “公告”采用奶油白贴纸标签，配深蓝描边与粗体文字；尺寸为 68 × 36rpx，文字为 22rpx，水平居中并固定在热区底部。
- 有可见公告时，喇叭以 1.4 秒周期持续摇动；角度依次为 `0° → -6° → +5° → -3° → 0°`，缩放依次为 `100% → 103% → 106% → 103% → 100%`。无公告时静止。
- 点击时入口短暂降低不透明度；关闭弹窗后仍按 `hasAnnouncements` 决定是否动画。
- 公告弹窗沿用公告列表与空态，并复用同一素材。

首页采用自定义导航，品牌标题与系统胶囊同行；状态栏、导航栏高度由设备窗口和胶囊位置计算。

## 验证入口

`node scripts/preview-home.cjs notice`（有公告）、`configured`（无公告）、`modal`（公告弹窗），输出保存在 `.tmp-preview/`。预览使用真实页面 WXSS 和公告 ViewModel 的测试数据；`tests/remote-data.check.js` 覆盖数据状态，`tests/home-prototype.check.js` 覆盖布局、素材和动画规则。
