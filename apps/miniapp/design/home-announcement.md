# 首页公告入口

使用内置 imagegen 生成暖色扁平喇叭，运行素材为 `../miniprogram/assets/home/announcement-megaphone.png`，256 × 256 像素透明 PNG。主体采用珊瑚橙，口沿为奶油黄，把手和尾部为深砖红；短宽把手完整显示，右侧保留两条声波。

## 布局与交互

- 点击热区 96 × 96rpx，白色圆底 84rpx 居中并带轻微投影，与搜索热区间隔 16rpx。
- 喇叭为 96rpx 独立前景层，允许溢出；把手落在白圈内，喇叭口和声波越出圆底上缘及右缘。旋转中心按素材把手连接处设置为 `30% 61%`。
- 右下角固定显示深砖红底、白字“公告”标签，和圆底共用点击入口。
- 有可见公告时，喇叭以 1.4 秒周期持续摇动；关键帧角度依次为 `0° → -6° → +5° → -3° → 0°`，缩放依次为 `100% → 103% → 106% → 103% → 100%`。无公告时静止。
- 按压只将圆底缩放至 96%，标签位置保持固定；关闭弹窗后仍按 `hasAnnouncements` 决定动画。
- 公告弹窗沿用列表与空态，使用同一张喇叭素材。

首页采用自定义导航，品牌标题与系统胶囊同行。状态栏和标题栏高度由实际窗口信息、胶囊位置计算，搜索位于标题栏下方。

## 素材生成规范

透明背景、圆润厚实的扁平几何侧视图，喇叭口向右上约 10°；珊瑚橙主体（#FF714F）、奶油黄口沿（#FFE5A0）、深砖红把手与尾部（#982F28）。短宽把手，完整轮廓，两条短声波；大色块、简洁细节，适合 48px 显示。主体居中并留透明边距，白圈、文字标签和投影由页面绘制。

## 验证入口

`node scripts/preview-home.cjs notice`（有公告）、`configured`（无公告）、`modal`（公告弹窗），输出保存在 `.tmp-preview/`。预览使用真实页面 WXSS 和公告 ViewModel 的测试数据。交互状态由 `tests/remote-data.check.js` 覆盖，布局、素材及动画规则由 `tests/home-prototype.check.js` 覆盖。
