# 题库工作台设计与实现说明

更新日期：2026-10-31。

本轮提供可以在浏览器操作的第一版题库工作台，继续沿用 React、Arco Design、TanStack Query 和现有本地 Mock，不新增依赖。

## 页面结构

侧栏按运营概览、院级管理、题库工作台排列。

- `/question-banks`：左侧课程目录，右侧题库列表。支持课程搜索及维护、按课程查看题库、题库搜索与发布状态筛选。
- `/question-banks/:id`：具体题库的内容工作台，提供题目管理、基本信息、展示范围三个页签。
- 新建及编辑题库使用抽屉；从列表可以直接编辑基本信息或展示范围。新建时也可就地建立课程。

一门课程可以有多份题库，同课程下题库名称不能重复。教材、版本及用途通过题库名称和教材说明区分，学院、专业、年级用于匹配展示对象。

## 内容维护

- 课程支持创建、修改名称、启停和删除；包含题库或学生自选课程关联时受到删除保护。
- 题库新建后为草稿，可先保存基本信息，再补齐题目、说明和展示范围。
- 题目支持单选、多选、判断、填空、简答，以及阅读理解题组，支持创建、查看、编辑、启停、删除、搜索与题型筛选。
- 章节先采用一层结构，支持新增、改名、上下排序和空章节删除；编辑题目时可调整章节或设为未分章。
- 一道题属于一份题库，本轮未增加共享题目池或组卷功能。
- 已有题目或学生选择的题库不能直接更换课程。存在题目、章节、学生选择或反馈时，题库删除受到保护，可改用下架或归档。

## 填空、简答与阅读理解

| 类型 | 维护内容 | 交互约定 |
| --- | --- | --- |
| 填空题 | 题干标记、逐空可接受答案、匹配设置、解析 | 使用 `{{1}}`、`{{2}}` 标记，每个编号只出现一次；每空可维护多个答案，一行一个；支持设置忽略大小写、忽略首尾空格 |
| 简答题 | 题干、参考答案、评分要点、解析 | 每行一条评分要点，供学生自评；当前未提供自动判分、人工批阅或 AI 评价 |
| 阅读理解 | 题组标题、共用材料、按顺序排列的小题、可选材料说明 | 小题复用五种基础题型，可添加、编辑、上下排序或移除；不嵌套阅读题组 |

填空题最多 20 个空，每空最多 20 个可接受答案；简答题最多 30 条评分要点；每个阅读题组包含 1 至 50 道小题，材料最多 20000 字。

阅读材料自身不计题数，课程题库列表、题库详情、章节、运营概览及导入数量统一按实际小题统计。题目列表将阅读题组作为一条记录，可展开查看小题，再进入完整详情。按某种基础题型筛选时，包含该题型的阅读题组会一并显示；搜索覆盖材料及小题题干、选项。

题组整体管理章节和启用状态，小题不单独发布。材料说明可选，但每道启用小题都需要答案与解析。修改材料、空位答案或匹配规则、参考答案、评分要点、小题内容及顺序均递增内容版本；状态变化不递增内容版本。已保存题目及阅读小题的题型固定，小题使用稳定标识保持排序后的答案关联。

旧的三种题型及本地数据继续兼容，不清空现有演示记录。以上均为管理端维护规则，真实学生作答、填空判题与简答自评流程尚未接入。

## 展示范围

两种模式二选一：

| 模式 | 行为 |
| --- | --- |
| 全校可见 | 不限定学生的学院、专业和入学年份 |
| 指定范围 | 配置多组学院、专业、年级条件；组内同时满足，组间满足任意一组 |

每组可以选择全部专业或全部年级，也可以一次勾选多个年级。界面按一组多年份呈现，保存为多条明确条件；范围摘要展示最终条件。指定范围的全空条件不代表全校可见，面向全校应明确选择全校可见。

学院、专业和年级直接读取院级管理目录。修改学院时清空下级选择，修改专业时清空年级；保存时再次校验归属及目录中的有效年份。旧的未明确学院、仅设置专业的条件会在编辑时补充对应学院。

学生资料匹配预览同时检查范围、题库发布状态、课程启用状态和可练习题目数。范围匹配的草稿仍提示发布后才展示。该预览表达列表筛选规则，未增加资料修改审批或访问鉴权。

## 发布与记录保留

发布前检查课程启用、题库说明、至少一道启用题目、启用题目的格式及解析、展示范围和章节归属。检查失败时标明原因，不能确认发布；真正写入时由 Gateway 再次校验。

草稿可以暂缺展示范围，已发布题库不能保存未配置的范围。切换为全校可见后清空指定条件。下架和归档退出学生列表，保留题库内容及已有记录。

已发布题库的最后一道启用题目不能直接停用、迁移或删除，需要先下架再整理。题干、选项、答案或解析修改后递增题目内容版本，反馈保存的原题快照保持不变。

## 批量导入

支持多个 JSON 文件，提供识别状态、错误信息、题目预览、文件排序和移除，以及统一归入章节。每个文件最多 5 MB、2000 题，一次最多 20 个文件、合计 10000 题；阅读理解按小题计数，文件预览同时标明实际题数与记录数。

可以按六种题型切换 JSON 格式示例，并在导入预览中展开完整题干、阅读材料、答案及评分要点。支持管理端字段及小程序导出的 `questions` 数组和题型别名；新增类型为 `FILL_BLANK`、`SHORT_ANSWER`、`READING`，别名分别为 `fill`、`short`、`reading`。

填空答案存入 `blanks[].answers`，匹配设置为 `blankMatch.ignoreCase` 和 `blankMatch.trimWhitespace`；简答使用 `referenceAnswer` 与 `scoringPoints`；阅读使用 `passage` 和 `subQuestions`，小题可省略 `id`，导入时自动生成。非选择题的 `options`、`correctAnswer` 可省略，保存后统一为空数组。

全部文件识别成功且整批校验通过后追加写入，不覆盖原题；失败时保留文件与预览结果，便于修正。阅读小题错误同时包含文件题号与小题序号，整批失败不会留下部分写入。

## 实际边界

本轮仅覆盖管理端页面及浏览器本地 Mock。真实答题端、跨端资料同步、题库列表接口、服务端权限和数据库尚未接入。真实练习中的题目版本固定与判题快照仍需后端实现；管理端内容版本和反馈快照不代表已完成这部分能力。

日常编辑保存到本浏览器，切换 Playground 场景会重置演示数据。课程、题库、题目与已有院级目录共用同一份本地数据，旧演示记录继续保留。
