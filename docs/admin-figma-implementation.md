## 实现与复用

- 保留 React、TypeScript、Vite、Arco Design、TanStack Query、Zustand，不新增应用依赖。
- 复用 `AdminContentGateway`、原有学院/专业/科目/题库/题目 DTO、查询缓存和 CRUD 页面；补充运营数据模型和 Gateway 方法。
- 保留旧的内容管理入口，在题库工作台和权限页提供导航。题库列表可直接进入对应题库的题目列表，新建题目默认使用当前筛选的题库。
- 使用 Figma 的画布色 `#f3f7fd`、主色 `#087bff`、白色卡片与边框色 `#dce4ef`；导航、统计图标和登录插图落在 `src/assets/figma/`，运行时没有临时 Figma 地址。
- 图表由当前 Mock 记录计算，数据变化会更新；保留原有演示题库与题目，不把原型中的 12,480 等示意数字写成固定业务统计。
- 没有照搬原型描摹层中的重叠碎片和乱码；公告正文以安全的文本标记实现加粗、斜体和分段，预览不会执行 HTML。

## 交互与数据规则

1. 公共课对所有人员开放，不能被个人屏蔽；停用的科目仍不可见。
2. 专业只能选择所属学院已开放的科目。缩小学院范围时，相关专业超出范围的选择同步移除。
3. 人员继承专业范围，可以屏蔽继承项或单独添加其他科目；停用学院或专业后，相关继承范围不生效。公共课和个人添加独立计算。
4. 已有关联专业、科目、题库、题目或用户时，相关删除受到保护；迁移仍有用户的专业会被拒绝。删除科目时同步清理可见性规则，避免遗留失效 ID。
5. 批量导入在全部题目验证成功后一次写入。单个坏题会阻止整批写入，错误提示包含题号；文件可移除或重排。导入追加新记录，不覆盖原有题目。
6. 新管理员密码在本地演示 Store 中保存摘要，不通过列表或日志返回。当前登录账号、最后一个启用管理员不能被删除或停用。
7. 写操作与登录行为产生本地操作日志，保留最近 1,000 条；日志中的 IP 来源明确显示“本地演示”。
8. 切换 Playground 场景会重置演示数据并刷新查询；已发出的旧场景请求不得写入新场景。

## 当前边界

`apps/api` 和 `packages/contracts` 仍为空骨架，本次交付为可独立运行的管理端与本地 Mock 闭环，没有真实 HTTP API、数据库、RBAC 或跨端推送。浏览器中的本地数据和登录校验不作为生产安全边界。

公告的指定用户、展示端及发布时间已保存。定时公告在列表每 30 秒刷新或再次读取时计算到期状态；关闭页面后没有后台发布任务，也不会向现有小程序或 Web 自动推送。

失败锁定、会话超时、新密码规则在本浏览器演示中生效；新设备验证、首次登录改密暂不可启用，需要真实身份服务。现有 `admin / mock` 保留兼容；新建或重置密码执行所保存的密码规则。

活跃度使用演示访问记录；双端同日活跃人数去重，登录端分布与新/回流用户图采用人次。排行榜的活跃天数根据当前日期范围计算，刷题数展示用户累计值。7 日留存采用相邻两周活跃用户交集的演示口径。

切换场景会恢复该场景的数据，请勿在演示环境存放正式业务数据。

## 验证方式

```bash
cd apps/admin
pnpm test
pnpm build
pnpm dev
```

默认端口为 `5174`，占用时 Vite 会选择下一个可用端口。演示账号：`admin / mock`。

自动化测试覆盖导入兼容、整批失败回滚、数据关联、权限继承、公告发布、账号保护、密码与会话、失败锁定、日志筛选及活跃度日期范围。浏览器验收另行检查实际表单保存、公告预览/发布、账号登录、文件上传、页面加载、场景切换和手机布局。

2026-10-25 实际验证结果：

- 20 项 Vitest 测试全部通过，TypeScript 检查及 Vite 生产构建通过。
- 登录及各页面加载通过，没有浏览器运行时异常；Figma 素材已检查本地文件与实际渲染尺寸。
- 公共课保存、用户编辑与科目管理、公告预览与立即/定时发布、新账号登录、正常 JSON 导入和日志联动通过。
- 无效文件会阻止确认导入；写入失败保留原数据并可重试；空数据、请求失败、慢请求和 1000 道题场景切换通过。
- 390px 手机宽度下页面无横向溢出，抽屉导航可打开并在跳转后关闭。
- 构建仍有共享 JavaScript 包超过 500 kB 的非阻塞提示；本次未引入额外拆包依赖。
