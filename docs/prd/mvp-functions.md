# QandA MVP 功能清单

- 科目选择
- 题库选择
- 未完成练习检测与继续练习
- 答题数量配置
- 顺序 / 随机出题
- 立即反馈 / 统一反馈
- 自动下一题开关
- 不计时 / 练习计时
- 单选题
- 多选题
- 判断题
- 上一题 / 下一题
- 答题卡跳题
- 当前题、已答、未答状态
- 答题过程本地持久化
- 异常退出后的练习恢复
- 主动退出并保存
- 提交 / 交卷二次确认
- 未答题数量提示
- 完整 Session 一次性提交
- 提交失败后的本地待同步
- 结果总览
- 错题解析列表
- 全部题目列表
- 正确 / 错误 / 未答筛选
- 本次题目搜索（题干 + 选项）
- 题目详情查看
- 正确答案与解析查看
